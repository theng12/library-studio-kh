      Setup & help

      How Library Studio KH fits together, what each companion app does, and how to check and fix the common problems. This guide works offline.

      How the pieces fit

      Library Studio KH is the control room. The companion apps do the work: qBittorrent downloads, Sonarr, Radarr and Lidarr look after the library, and Prowlarr finds sources. Each companion stays a separate program, so it can update or recover on its own. A broken subtitle tool should not stop movie downloads, and updating Library should not replace the whole stack.

      Most people never need to open a companion app. Use Advanced → Open companion app only for a setting or repair that Library does not cover yet. That action is planned; for now, open the companion app from your normal applications list.

      Two ways to start

      Most people never need to open a companion app. Choose the path that matches this computer.

      Set up this computer
      Why
      Library can install and configure the companion apps you choose, so the whole stack starts in one place. Existing apps and files are kept.
      Required

      Connect to an existing library
      Why
      It lets this device use a library that is already set up on another computer, without installing anything here.
      Required
      Optional. Use this for a home server or a host that is already running.
      Check
      Sign in succeeds and Activity lists the connected apps. No companion apps are needed on this device.
      Fix
      Ask the host owner for an account. If the host has no owner account yet, create it on that computer first.
      qBittorrent — downloads
      Why
      It downloads the files that Sonarr, Radarr and Lidarr ask for, and any torrent you add by hand.
      Required
      Yes, for downloading. Without it, Find & add and Downloads cannot work.
      Check
      Activity shows qBittorrent connected. Settings holds its address, username and password.
      Fix
      Start qBittorrent, then correct its address and sign-in in Settings. Keep its own remove-files action off; Library does the library check before removing anything.
      Sonarr — TV
      Why
      It tracks shows and episodes, monitors new releases, and tells Library when a download is fully in the library.
      Required
      Optional. Required only if you collect TV.
      Check
      Activity shows Sonarr connected, My library lists TV, and Find & add returns shows.
      Fix
      Start Sonarr and add its address and API key in Settings. The key is under Sonarr's Settings → General.
      Radarr — films
      Why
      It tracks films, monitors new releases, and confirms when a film is fully in the library.
      Required
      Optional. Required only if you collect films.
      Check
      Activity shows Radarr connected, My library lists films, and Find & add returns films.
      Fix
      Start Radarr and add its address and API key in Settings. The key is under Radarr's Settings → General.
      Lidarr — music
      Why
      It tracks artists and albums, monitors new releases, and confirms when an album is fully in the library.
      Required
      Optional. Required only if you collect music.
      Check
      Activity shows Lidarr connected, My library lists music, and Find & add returns artists.
      Fix
      Start Lidarr and add its address and API key in Settings. When adding music, choose both a quality profile and a metadata profile.
      Prowlarr — sources
      Why
      It keeps indexer settings in one place and syncs them to Sonarr, Radarr and Lidarr.
      Required
      Optional, but recommended. Library never adds its own downloader or indexer.
      Check
      Open Sources to see Prowlarr's configured sources, reported health, application links and the source lists in each library app. Refresh status to check again.
      Fix
      Start Prowlarr, add indexers there, and run its sync to the library apps. Then add its address and API key in Settings.
      Bazarr — subtitles Planned
      Why
      It finds and manages subtitles for the library.
      Required
      Optional. Not controlled here yet.
      Check
      Not available in this build. Use Bazarr's own settings and health page.
      Fix
      Planned optional integration. When it arrives, Library will add connection health, setup help and supported workflows.
      Whisparr — optional library app
      Why
      Connects an optional Whisparr library using its own address and API key.
      Required
      Optional and off by default. Enable its connection in Settings, or explicitly select it in Set up this computer.
      Check
      Installation and first-run compatibility remain unverified. A saved address is not a running-app check. When enabled, Activity reports connection health; setup reports failed or unavailable checks without claiming Ready.
      Fix
      Connect an existing app in Settings using its API key from Settings → General. Leave the key empty to keep a saved key. If setup cannot verify the official package or connect, read its error and keep Whisparr off until resolved. Turning the connection off keeps its saved address and key.
      LazyLibrarian and Mylar3 Planned
      Why
      These are optional library apps for books, comics and other collections.
      Required
      Optional. Not controlled here yet.
      Check
      Not available in this build. Use each app's own settings.
      Fix
      Planned optional integrations. Each will bring useful controls, setup help and connection health when it is added.
      Storage and the NAS
      Why
      Downloads land in a local folder and the library lives on a NAS. Library checks free space and whether the library folder can be reached.
      Required
      Yes, for a NAS library. Both folders are settings, never fixed paths.
      Check
      Activity shows free space and says when the NAS library folder cannot be found.
      Fix
      Set both folders in Settings and mount the NAS on this computer. Library does not store NAS passwords; use the NAS's own login.
      Monitoring and quality
      Why
      Monitored items are watched for new releases. Quality profiles decide what counts as good enough, root folders decide where files go, and Lidarr also needs a metadata profile.
      Required
      Choose a live profile and root folder for every add. Lidarr also requires a metadata profile.
      Check
      My library has a Monitored toggle per item. Find & add shows the app's live profiles and folders before you commit.
      Fix
      Create profiles and root folders in the companion app, then reopen the add dialog. If the list is empty, that app has nothing configured yet.
      Metadata, languages and subtitles
      Why
      Original language describes the title; reported audio and subtitles describe files. They can differ.
      Required
      Metadata comes from the owning library app. Subtitles are optional and need Bazarr, a language profile, a provider and imported/indexed media files.
      Check
      Open a film or series and expand Subtitles and file languages. English searches run only when requested here. Search requested is not confirmation of a download; refresh to check availability.
      Fix
      Connect and enable Bazarr in Settings. If no files are reported, wait for import and sync/index them in Bazarr. Sync can trigger configured subtitle searches. Library's switch does not stop background work independently enabled in Bazarr.
      Cleanup and removal safety
      Why
      Cleanup frees local disk space after a download is safely in the library.
      Required
      Optional and off by default. Staged cleanup needs macOS, a local managed folder and a verified complete import. The old permanent-delete path is retired.
      Check
      Open Cleanup to edit the policy, Preview eligible files and see import proof, blockers and restore paths. Settings inside your apps has separate Apply controls for supported native settings.
      Fix
      Resolve reported connection or verification blockers before enabling cleanup. Local copies pass through Library’s _trash and macOS Trash before permanent removal; low-space removal affects eligible Library-owned Trash only. NAS files and unrelated Trash stay protected.
      Startup, login and sleep
      Why
      The Library host must be running for browser control. The stock download and library apps run independently and can continue working while Library is unavailable.
      Required
      Yes while you use the browser.
      Check
      Activity loads. With an installed background host, closing the desktop window leaves browser access available.
      Fix
      Start the installed Library host, or keep the desktop app open in desktop-only mode. Built-in service setup is still planned. Keep the host awake for remote access; OS login and NAS availability are separate setup steps.
      Private remote access
      Why
      It lets your phone use the library without exposing it to the internet.
      Required
      Optional. Off by default.
      Check
      Settings shows the Tailscale address and whether access is on. Both devices must be on the same tailnet.
      Fix
      Install Tailscale and sign in on both devices, then turn on access in Settings. This is HTTP over your Tailscale network: encrypted by Tailscale, but not HTTPS, and the session cookie is not marked Secure. Do not port-forward.
      Troubleshooting
      App shows not connected
      Start it, then check its address and API key in Settings. The key is in the app's own General settings.
      Cannot create the owner account from a phone
      Owner setup only works on the host computer. Open Library Studio KH there, create the account, then sign in from the phone.
      Signed out unexpectedly
      Sessions last 12 hours unless Remember this device was ticked, which lasts 30 days. Sign in again.
      Find & add has no profiles or folders
      The companion app has nothing configured. Create a quality profile and a root folder there, then reopen the add dialog.
      Add says the selection is not valid
      The app changed its profiles or folders. Reopen the add dialog so Library loads the live options again.
      NAS folder missing
      Mount the NAS on this computer. Library will not remove files while the library is unreachable.
      Page will not load
      The server must be running. Open the desktop app and check the Tailscale connection.
      Remote link does not work
      Both devices must be on Tailscale. Use the exact address from Settings. The address is HTTP, not HTTPS.
